# athulvrajeev.github.io — personal academic website

Single-page site (plain HTML/CSS, no build step). Live address once published: https://athulvrajeev.github.io

## Files
- `index.html` — the whole website (edit text directly in this file)
- `files/Athul_Rajeev_CV.pdf` — public CV (no phone number, no referee contacts, no invention disclosure)
- `images/` — add your own pictures here (optional; the site already shows drawings if they are missing)
  - `profile.jpg` — square photo, at least 600 x 600 px (replaces the "AR" circle)
  - `project1.png` — nanoparticle + membrane snapshot (PCCP project)
  - `project2.png` — TRPV1 membrane system
  - `project3.png` — PMF / convergence plot from the ABF workflow
  - `project4.png` — COMSOL velocity field / particle trajectories
  - Use 16:9 images (e.g. 1600 x 900 px). Do NOT use figures from the Patent folder (confidential until filed).

## Publish on GitHub Pages (about 5 minutes)
1. On github.com click **+ > New repository**.
2. Repository name: **athulvrajeev.github.io** (exactly this). Public. Do not add a README. Create.
3. Click **uploading an existing file**, then drag everything INSIDE this folder (index.html, README.md, files/, images/) into the page.
4. Commit message: "Add website" > **Commit changes**.
5. Go to **Settings > Pages**. Under "Build and deployment": Source = Deploy from a branch, Branch = **main**, folder = **/ (root)** > Save.
6. Wait 1-2 minutes, then open https://athulvrajeev.github.io

## Updating later
Edit the file on github.com (pencil icon) or upload a new version with the same name. Changes go live in about a minute.
When the CV changes, upload the new PDF as `files/Athul_Rajeev_CV.pdf`.
